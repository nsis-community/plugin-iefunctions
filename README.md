## Installation

Download the installer or archive from the [Releases page](https://github.com/nsis-community/plugin-iefunctions/releases).

If you downloaded the zip archive, extract it into your NSIS folder: it adds `IEFunctions.dll` to `Plugins/<variant>/`.
